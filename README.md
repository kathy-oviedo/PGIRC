# Plataforma de Gestión Inteligente de Rutas y Catálogo - PGIRC

Proyecto académico desarrollado en Java para aplicar estructuras de datos
en la solución de problemas relacionados con comercio electrónico y logística.

## Funcionalidades

- Árbol Binario de Búsqueda (ABB)
- Inserción y eliminación de nodos
- Recorridos inorden, preorden y postorden
- Búsqueda de productos por código
- Representación de rutas mediante grafos
- Algoritmo de Dijkstra
- Manejo de rutas bloqueadas
- Cálculo de camino crítico

## Ejecución

Compilar:

```bash
javac PGIRC.java
```

Ejecutar:

```bash
java PGIRC
```

Tecnologías
- Java
- Visual Studio Code
- GitHub
